A one-sentence excuse a house cat gives in the five seconds after knocking
a glass off the table, written for make.fun's **Five Seconds to Explain the
Glass** bounty. The program writes a single sentence of at most 200
characters to `/output/entry.txt`.

## The excuse

> That glass parked itself in my sunbeam, on my table, and gave me that look, so I evicted it — the floor is its new address now.

127 characters, one line. The angle is a territorial cat that does not
apologise and does not confess: the glass parked itself in the cat's
sunbeam, on the cat's table, and gave the cat that look — so the cat
evicted it, and the floor is its new address now. No gravity joke, no
slippery edge, no "it was already falling".

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
